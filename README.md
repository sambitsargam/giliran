# Giliran

**Savings circles nobody can run away with.** A paluwagan / arisan / kutu where a smart contract on Base holds the pot instead of an organiser. Members join with a phone passkey, and every on-time payment builds a portable Savings Passport.

> Work in progress for the Web3 for Social Good 2026 hackathon (Tech Track).

- `contracts/` — Foundry project (Circle escrow, factory, Savings Registry)
- `web/` — Next.js app
- `docs/` — architecture, threat model, judge walkthrough
